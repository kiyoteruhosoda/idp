# ADR-0068: 開いたままの管理コンソールは、問い合わせて新しいバージョンに気付く

- Status: Accepted
- Date: 2026-10-04
- 関連: `docs/adr/0034-version-information-is-not-public.md`（稼働中のビルドを公開面に出さない）、
  `docs/adr/0063-member-notes-and-applications-on-the-member-page.md`（ホーム画面へ入れるマニフェスト。
  service worker は置かない）

## 背景

管理コンソールはホーム画面に入れて使える（ADR-0063）。入れて使うと、画面は何日も開いたままになる。
サーバが描く画面なので、次の画面へ移れば新しいバージョンになるが、**開いたままの 1 画面は、配られた
ことに気付けない**。持ち主から「変更通知が出ない」と指摘された（task #256）。同じ持ち主のほかのアプリ
（SPA）は、service worker の入れ替わりを合図に「新しいバージョンがあります」を出している。

あわせて、本番の管理コンソールのフッターが `v0.1.0 (unknown)` だった。ビルドする側（deck と deploy-repo
の `build-image.yml`）は、どのアプリにも同じ名前で `COMMIT_HASH` を渡しているが、Dockerfile は
`IDP_GIT_VERSION` しか受けていなかった。

## 決定

### 1. service worker は足さない。画面が稼働中のビルドを問い合わせる

共通レイアウト（`console/layout.html`）は、描いたときのビルドの表記（フッターと同じ
`v0.1.0 (abc1234)`）を `data-build` に持つ。`assets/console.js` が `GET /{tenant_id}/admin/version/current`
の返す文字列と比べ、違えば「新しいバージョンがあります。［再読み込み］」を出す。

- 問い合わせるのは画面が見えているときだけ —— 別のタブから戻ったとき（`visibilitychange`）、戻る・進むで
  復元されたとき（`pageshow`）、5 分おき。直前の問い合わせから 1 分は空ける。
- 出した知らせは押すまで消さない。押すと `location.reload()`。
- 未ログイン（302）・通信の失敗・前段の停止ページ（200 以外）では何もしない。

### 2. 問い合わせる口は管理コンソールの内側に置く

`/admin/version/current` は `resolve_admin` を通す。稼働中のコミットを無認証の面に出さない、という
ADR-0034 をそのまま守る。知らせの部品（`data-build`）も、ログイン済みの画面にだけ描く。

### 3. Dockerfile は `COMMIT_HASH` も受ける

`IDP_GIT_VERSION` が空なら `COMMIT_HASH`、それも無ければ `unknown`。`IDP_GIT_VERSION` を明示する経路
（`scripts/build.sh`・docker compose）は今までどおり。

## 影響

- 管理コンソールを開いたままにすると、5 分に 1 回 whoami（web → api）が 1 本増える。
  ⚠ **whoami は SSO セッションの有効期限を延ばさない**（延ばすのは認可要求のときの `sso_restore` だけ）
  ので、「操作が無いときにログアウトする」は効いたままである。ここを延ばす作りに変えるときは、
  この問い合わせが利用者の操作として数えられないようにすること。
- 入れ替えの途中（古い pod と新しい pod が両方答えるあいだ）は、再読み込みした画面が古い pod に当たり、
  もう一度知らせが出ることがある。入れ替えが終われば止まる。
- 利用者向けの画面（ログイン・アカウント設定）には出さない。公開面のフッターにバージョンを出さない
  という ADR-0034 の決定 1 も変えていない。

## 却下した案

- **service worker を入れて、入れ替わりを合図にする。** 認証の後ろの画面を持つアプリでは壊れやすく
  （スクリプトの取得がログインへ飛ばされると登録ごと失われる）、この画面にオフラインで見せられるものも
  無い（ADR-0063）。知らせのためだけに入れる理由が無い。
- **無認証の口で、ビルドを読めない形（ハッシュ）にして返す。** リポジトリを読める相手は全コミットの
  ハッシュを作って突き合わせられる。秘密鍵を混ぜれば防げるが、認証の内側に置けば要らない。
- **アセットの `?v=`（内容ダイジェスト）を比べる。** 既に公開されている値だが、Rust だけを直した
  バージョンでは変わらない。
